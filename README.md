# 教育部來文公文分析儀表板

互動式 HTML 儀表板，分析教育部（含所屬機關）來文公文資料。

## 資料範圍

- **期間**：2025年7月 ～ 2026年5月（11個月）
- **總筆數**：1,743 件
- **來源**：公文收文清單 CSV

## 儀表板內容

- KPI 卡片：總件數、月份分布、最高來文月份、司處數
- 複合圖表：每月件數（長條）＋累計趨勢（折線）
- 橫條圖：各司處來文件數排行
- 圓餅圖：各司處佔比
- 詳細表格：司處統計、來文機關彙整

## 使用方式

直接用瀏覽器開啟 `index.html`（需要網路連線載入 Chart.js）。
